# Plano 004

Configurar a imagem da API com HTTPS via proxy, PostgreSQL, SMTP, chave RAWG e volume persistente para chaves do ASP.NET Core Data Protection. Aplicar a migration como etapa separada. O Flutter usa URL de API por ambiente. A entrega inclui APK e registro do roteiro executado em homologação.

O ambiente local usa Docker Compose para o banco e Mailpit. A automação de CI da API executa os testes contra PostgreSQL.
