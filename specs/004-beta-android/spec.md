# 004 Beta Android

Distribuir um APK privado para validar o fluxo completo em Android com uma API de homologação por HTTPS.

## Aceite

- Um aparelho físico e um segundo aparelho ou emulador conseguem acessar a mesma biblioteca com as mesmas credenciais.
- O fluxo de aceite inclui confirmação, recuperação, cadastro manual, importação, atualização e exclusão.
- Os logs do servidor permitem correlacionar falhas com a requisição sem registrar segredos.
