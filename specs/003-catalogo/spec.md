# 003 Catálogo RAWG

Uma pessoa pesquisa por nome, escolhe um jogo e seleciona uma plataforma para adicioná-lo. A biblioteca mostra título, plataforma e capa, quando disponível. Jogos importados permitem alterar o status e remover a entrada.

## Aceite

- A API valida que o jogo e a plataforma existem no catálogo.
- O mesmo par jogo e plataforma só aparece uma vez como importação na mesma conta.
- Se o catálogo falhar, a interface permite tentar de novo. A biblioteca e a adição manual continuam disponíveis.
- As telas que exibem dados RAWG mostram crédito com link.
